# HTML output build rule

All new marketing webpages, lead demos, proof hubs and HTML showcases require the
September 18 creator-credit contract. Preserve existing footer text and add the
canonical final row. Use scripts/creator-credit.mjs in the owning writer, or create
a new output version with scripts/build-credited-artifact.mjs. Never overwrite an
approved source artifact or its old hash to imply historical compliance.

The existing publish-unlisted-static-proof-godaddy.sh gate now requires exact
credit HTML before publication. There is no price-tier bypass. Any explicit owner
override requires an exact documented artifact exception and reviewed gate change.
New output still needs its existing rights/content/publication approval. This
mandate does not authorize launching unpublished customer work.

HyperFrames video-composition HTML is not a webpage: preserve frame geometry and
historical render evidence. Its future interactive HTML wrapper needs the credit;
video end-card decisions stay in the existing media design process. Existing stills,
MP4s and immutable approval evidence are excluded from this HTML retrofit.
