# Local video studio: alternatives and hardware reality

Research checked: 2026-09-19. Recommendations below are architectural judgments; source capabilities and measured upstream benchmarks are identified separately. An upstream capability is not proof of Fritz's installed version or computer.

## Opinionated choice

The cheapest dependable production line starts with the tools and assets already owned: authored motion in HyperFrames, narration recorded once or generated by a separately verified local voice tool, reusable images/footage, then deterministic exports. Use MoneyPrinterTurbo for fast narrated draft montages. Add local AI-generated movement only where a specific shot earns the extra rendering time and uncertainty.

FAMtastic's purposeful difference can come from the concept and edit: an ordinary action in an impossible setting, one surprising transformation, bold typography, and a recognizable creative rule. Buying or running a large generative model for every frame is not a prerequisite for that. This is a creative recommendation, not a measured claim about campaign conversion.

## Alternatives compared

| Choice | Useful role | Cost boundary | Decision for this build |
| --- | --- | --- | --- |
| Existing HyperFrames | HTML/CSS/media compositions with seekable animation and deterministic MP4 rendering | Apache-2.0 application; local rendering does not require buying generation credits. Assets, fonts and model outputs have their own rights. | Primary designed-motion renderer; reuse existing installation. |
| Remotion | Programmatic video authoring for a React-oriented codebase | Current free license covers individuals and companies of up to three people; larger organizations/collaborations need company terms. Automation pricing lists $0.01/render with a $100/month minimum for that licensed tier. | Credible alternative, particularly if existing React compositions need reuse. It is not inherently paid for a solo creator, but switching now adds a second renderer and a future license boundary. |
| Existing MoneyPrinterTurbo | Local image/video montage, supplied narration, transcript-driven draft reels and batches | MIT application; cloud LLM/media/voice/music selections remain separately metered. Edge TTS has no API key requirement but is an online service. | Optional draft worker. Explicit local inputs avoid accidental provider calls. |
| Shotcut | Hands-on finishing, trimming, sound adjustment and visual review | Free/open-source cross-platform editor. | Useful manual finishing escape hatch if a specific edit costs more to automate than to perform. Not an automatic renderer substitution. |
| Local Kokoro-82M | Reusable synthetic narration files | Apache-2.0 weights; local setup and compute remain necessary. Hosted Kokoro is a separate service. | Small, plausible local voice option; generate WAV first, then feed the verified file into the studio. Recording Fritz remains the direct choice for his exact voice. |
| ComfyUI plus chosen local video model | Selected image-to-video or text-to-video shots | Running the UI locally does not make every workflow local: partner/API nodes may call services. ## What a 16 GB Apple Silicon Mac can reasonably target

The repository's saved workstation profile says Apple Silicon with 16 GB unified memory. Run `doctor` on the actual workstation before treating that as current hardware. Unified memory is shared by the operating system, browser, renderer, models and applications; it is not 16 GB of separate graphics memory.

ComfyUI officially supports Apple Silicon using PyTorch MPS. It does not use MLX directly. That establishes platform support, not proof that a given model, resolution and clip length fit. [ComfyUI hardware documentation](https://docs.comfy.org/installation/system_requirements)

| Workload | Evidence | Practical interpretation |
| --- | --- | --- |
| Branded HTML motion, existing clips, images and supplied audio | HyperFrames renders these locally; MoneyPrinterTurbo does not require a GPU for its basic assembly route. | First production target. Benchmark throughput and memory with one render worker. |
| Small local narration or transcription | Kokoro is an 82-million-parameter voice model. Faster-whisper documents CPU int8 operation; its published small-model CPU benchmarks use approximately 1.5 GB RAM without batching. | Much more plausible than large video diffusion. CPU benchmark figures are not Mac timing promises. |
| Wan2.1 T2V-1.3B | Upstream reports 8.19 GB VRAM and roughly four minutes for a five-second 480p clip on RTX 4090. | This is a text-to-video NVIDIA benchmark, not a 16 GB Mac result or a claim about the larger image-to-video model. |
| Legacy LTX-Video 2B variants | Upstream offers smaller 2B distilled models and documents macOS MPS support. | A candidate for a constrained experiment after exact workflow/license checks. No verified 16 GB fit, speed or identity-quality guarantee here. |
| Current LTX-2.5 default stack | Official system requirements list NVIDIA 32 GB+ VRAM, 32 GB system RAM and 100 GB free disk. The current default model download is roughly 66 GiB. | Do not make this the default setup for a 16 GB Mac. Quantization/offload options do not establish acceptable performance on that machine. |

The legacy LTX page links checkpoint-specific licensing; the current LTX repository includes separate license files for model generations. Do not label the entire family unconditionally Apache-2.0 because one code package is.

## Lowest-cost proof sequence

1. Render a short authored ad from owned images, exact logo, typed copy and a supplied WAV. Freeze source hashes, installed versions, run time and output checks.
2. Reuse that finished timeline for aspect ratios and text variants. Measure successful output per minute of work, not just generator credit cost.
3. Run one MoneyPrinterTurbo local-input draft and compare the actual editing time saved. Preserve the drafted-vs-designed distinction.
4. For a scene that needs synthetic movement, isolate one model/workflow experiment. Close competing memory-heavy models, use the shortest supported clip and smallest supported resolution, and record peak memory and elapsed time. Keep failure visible and do not silently substitute an online provider.
5. Use the two reference movies as creative acceptance tests: shot intent, identity, composition, timing, typography, source sound/narration and logo must be reviewed. Metadata validity alone does not establish a successful recreation.

Provider spend can be zero on this local route. Electricity, hardware wear, downloads, storage and operator time still exist. Current receipts should report unmeasured costs honestly; no laptop completion-time estimate is defensible before the local benchmark.
