Do not extend the existing 300-second static-dispatch claim by pretending a
long creative run is static packaging. Add a distinct capability, runtime and
cost policy. Every stage must prove current ownership before external effects;
an expired heartbeat is not proof the previous provider operation stopped.
Unknown paid outcomes retain their reservation and require reconciliation.

## Reuse, not replacement

Recent customer repositories demonstrate the actual process: agent-authored
research and custom directions, managed image tools, local build scripts,
independent review, promotion bundle, canonical import and recorded notice.
Some provider IDs or full costs were not reported; preserve those unknowns.
Historical recipes are evidence, not permission to rerun selected artifacts.

website-delivery-swarm/provider_pipeline.py is a six-direction fictional
benchmark, not the unattended producer for requests 8/16/17. The packet bridge
packages existing artifacts; its name does not prove fresh generation. Existing
provider preflight commands can make real auth/model calls and are not offline
inventory. Do not use them casually in a source-verification run.

Required adapter inputs include recipe/source revision, approved direction
contract, tool capability allowlist, cost ceiling/reservation and read/write
roots. A normal routine must not require Fritz approval. Missing merchant,
rights, security or spending authority and repeated QA failures must escalate.

## Completion evidence

Use one controlled account and request through actual artifacts, private portal
links, captured branded mail, authenticated selection and one staging build.
Prove duplicate intake/selection/import, stale completion, worker interruption,
callback loss, budget exhaustion and restricted asset withdrawal. Captured mail
does not prove SMTP delivery; SMTP acceptance does not prove readership.

Before laptop independence: verify the cloud worker's exact capabilities,
shared claims and immutable inputs, then complete an unattended run with the
Mac unavailable. A cloud shadow observation or heartbeat running on the Mac is
not that proof. Preserve the customer-acceptance/settlement/final-launch boundary.
