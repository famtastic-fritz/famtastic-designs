# Coastal Current — first visual direction

Fritz authorized moving on from sufficiently comparable research on October 7, 2026. This proposal feeds site, image and graphic prompts. It does not depend on completing the deferred matched research run. Design acceptance remains pending.

## The idea

Make an HVAC service visit understandable: what a person notices, what an assessment starts, what needs approval and what happens next. Warm paper and ink recall the tangible service record. Cobalt, sea-glass layers and soft airflow contours translate it into a contemporary South Florida service identity. The receipt supplies information-design questions, not a public testimonial or a new price list.

Working name **Coastal Current** is an internal direction label, not a proposed company name. Until the client is identified, mockups say “YOUR HVAC COMPANY.” The receipt supplier's printed identity is not silently adopted as the site's client brand. Candidate message: **“AC trouble? Let’s make the next step clear.”**

## Visual contract

| Element | Direction and purpose |
| --- | --- |
| Display type | Fraunces, controlled soft forms, medium/semibold; short editorial headings with generous size and spacing |
| Functional type | Manrope, regular/medium/semibold; clear labels, service scope, forms and controls; avoid small/light text |
| Ink/paper | Navy `#142D45`, paper `#FAF7F0`, sand `#F1E9DC`; calm readable surfaces |
| Action | Cobalt `#17458C` for the primary request action; verify actual rendered contrast before implementation acceptance |
| Atmosphere | Sea-glass `#B9D6D0`, darker teal `#236C65`; warm coral `#B84A3D` as a restrained accent, never status by color alone |
| Shape | Asymmetrical S-curves, broad organic photographic windows, pill controls and curved section transitions; no straight decorative dividers or boxed service-card grid |
| Texture | Subtle paper grain on background layers only; continuous calm opaque text surfaces; no simulated handwriting in operational copy |
| Depth | Proposed build layers: paper base, broad sea-glass swell, cobalt airflow contour and sparse grain; text/actions remain independent HTML. The generated transparent asset combines decorative currents in one PNG, not four editable files |
| Service images | Distinct repair, maintenance and assessment vignettes; believable unbranded equipment/details and house setting; all generated imagery is illustrative |
| Personality | Practical warmth and flowing cadence; no beach-resort story, cartoon repair hero, urgency countdown or dramatic frozen-unit fear image |

The font recommendation uses the Google Fonts distributions, each with its retained license: [Fraunces OFL](https://github.com/google/fonts/blob/main/ofl/fraunces/OFL.txt), [Manrope OFL](https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt). A generated bitmap approximates type appearance; it does not load or prove those font files. Later use actual licensed font files, retain notices, and test fallback/zoom/readability.

“No straight lines” governs the decorative language and section edges. Text baselines, logical form order and real engineering geometry stay readable and believable. No essential control or information depends on a curved mask, image text or animation.

## The homepage composition

1. Literal air-conditioning label, symptom-led heading, honest request/call choices and unbranded equipment imagery. A broad airflow curve leads down the page.
2. Three staggered editorial service vignettes, distinct image crops and useful scope text. Repair/maintenance/assessment are evident before optional comfort-story modules.
3. “A clearer service story” uses a visibly fictional typed example: finding, approved scope, limit, and next step with a responsible role. The eventual service record also distinguishes approved scope from work actually performed.
4. Plain contact choice with the next-step distinction repeated where useful. Footer links preserve the six-page structure.

At mobile size, copy/action leads; image follows; service vignettes become a readable vertical sequence. Mobile v2 presents the hero and first service, rather than shrinking the full desktop page. Avoid overlays on labels, tiny caption text, horizontal service scrolling and fixed bars that cover the form or keyboard. Later implementation tests keyboard, focus, zoom, contrast, reduced motion and actual persistence separately.

## Prompt package and review

Full FAMtastic definition and pinned specialist texts are retained in panel packages. The user requested broad coverage; all design, marketing, paid-media and specialized categories are screened, with relevant product/testing/psychology/Technical Artist support. Out-of-scope specialties do not generate new projects. Three panels apply multiple reference profiles; this is not 125 independent market observations.

The available built-in image tool does not expose model selection. Because Fritz explicitly requested model controls at GPT Image 2.5 or better, generation uses the installed image skill's direct CLI path with `gpt-image-2.5-sunburst-2026-09-08`, an existing private credential and no raw receipt upload. The model is documented in [OpenAI's API reference](https://developers.openai.com/api/reference/resources/images/methods/generate). No model downgrade is authorized. API completion and a visually plausible mockup remain separate from a tested working site.

Owner review should evaluate atmosphere, typography, layered graphics and service hierarchy. Accepting the picture does not adopt every candidate service policy or authorize deployment.

The panel outputs are advisory proposals; this document and the selected version in the asset manifest define the synthesized candidate. The master palette above takes precedence over alternate panel swatches. Fraunces/Manrope are the intended implementation fonts; rendered lettering approximates their visual roles. A functional link underline may remain a recognizable interaction cue; the prohibition is on straight decorative rules, borders and section cuts.
