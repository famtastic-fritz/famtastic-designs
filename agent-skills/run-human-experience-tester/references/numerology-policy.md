# Numerology personalization policy

Numerology is permitted only as disclosed, optional creative framing. It may
adjust tone, examples, brainstorming prompts, visual exploration, and questions.
It is not a factual personality assessment and cannot override observed behavior,
stated preferences, research, accessibility needs, product scope, or consent.

Preserve master numbers 11, 22, and 33 when calculating a Life Path. Prefer a
derived number rather than collecting a birth date. If a birth date is supplied
for a one-time calculation, do not include it in the result or evidence ledger.

Run a neutral control comparison for any material recommendation. Record the
lens number, rule version, disclosure, affected presentation fields, protected
decision fields, and whether the control reached the same product conclusion.
