# Website delivery swarm proof contract

The proof passes only when the runner exits zero, emits three PASS markers, and
an absolute `Evidence:` path. Evidence must include exactly three scenarios,
anonymous and member lanes, three directions per scenario, one trace per invoked
specialist, evidence for every add-on, no invented prices, no external mutation,
preserved request identity, and a Playwright screenshot for each scenario.

Fixtures prove orchestration, decisions, evidence, and rendering locally. They do
not prove live research, domain availability, provider APIs, Drupal persistence,
Site Studio callbacks, production hosting, or customer acceptance.
